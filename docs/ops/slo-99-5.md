# SLO 99.5% + API P95 — Tier 2/3 Operations

**NFR-A01** · Monthly availability target for enterprise staging.  
**Tier 3:** API read P95 **≤ 200ms** on staging ([Ke-hoach-du-an.md](../../Ke-hoach-du-an.md)).

## SLI / SLO

| SLI | SLO | Window | Measurement |
|-----|-----|--------|-------------|
| API availability | **99.5%** | Calendar month | Synthetic `GET /health` + authenticated probe |
| **API read P95** | **≤ 200ms** | Rolling 7d | Prometheus `http_request_duration_seconds` · k6 `api-read.k6.js` |
| Webhook delivery P95 | ≤ 30s | Rolling 7d | OP-WIN-07 omnichannel metrics |
| Payment incident MTTR | ≤ 15 min | Per incident | On-call runbook |

## Error budget

- 99.5% monthly ≈ **3.6 hours** downtime budget
- Burn > 50% mid-month → freeze non-critical releases
- Burn exhausted → incident review + game day within 5 days
