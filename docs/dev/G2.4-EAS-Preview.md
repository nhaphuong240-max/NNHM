# Gate G2.4 — EAS Build Preview (Agent Mobile)

> **Gate:** Mobile app sale beta — offline-read inventory + booking · NFR-CM02 device lab  
> **App:** `apps/mobile` · Expo SDK 57 · UC-UX-01

## 1. Tiên quyết

| Item | Lệnh / ghi chú |
|------|----------------|
| Expo account | https://expo.dev/signup |
| Access token | https://expo.dev/settings/access-tokens → `EXPO_TOKEN` |
| EAS project | `cd apps/mobile && npx eas-cli init` (link slug `wereal-agent`) |
| API reachable từ điện thoại | Staging hoặc IP LAN — **không** dùng `localhost` trên thiết bị thật |

## 2. Cấu hình API URL cho preview

Sửa `eas.json` → `build.preview.env.EXPO_PUBLIC_API_URL`:

```json
"EXPO_PUBLIC_API_URL": "http://192.168.x.x:3000/api/v1"
```

Hoặc override qua EAS Secret trên expo.dev (Project → Secrets).

## 3. Build preview (local)

```bash
export EXPO_TOKEN=your_token
export EAS_PROJECT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

cd WEREAL/apps/mobile
npm ci
chmod +x scripts/eas-preview.sh
./scripts/eas-preview.sh android preview
```

| Profile | Output | Use case |
|---------|--------|----------|
| `preview` | Android APK · iOS internal | **Device lab G2.4** |
| `preview-simulator` | iOS simulator `.app` | QA trên Mac |
| `development` | Dev client APK | Debug native modules |

## 4. CI — GitHub Actions

Workflow: `.github/workflows/eas-preview.yml`

1. Repo Settings → Secrets → `EXPO_TOKEN`
2. Optional: `EAS_PROJECT_ID`, `EXPO_PUBLIC_API_URL`
3. Actions → **EAS Preview (G2.4)** → Run workflow → chọn `android` / `ios` / `all`

## 7. Troubleshooting

| Lỗi | Fix |
|-----|-----|
| `Invalid project ID` | `eas init` + set `EAS_PROJECT_ID` |
| API offline trên device | Đổi `EXPO_PUBLIC_API_URL` sang IP máy dev |
| iOS signing | Cần Apple Developer · EAS managed credentials |
| Push không nhận | Preview APK cần FCM/APNs production — pilot dùng local stub |
